
1. Reader reliability harness

Turn the journeys we have been debugging into reusable tests across short, long, and irregular works: deep-link; scroll forward/backward; switch single/two-column; page turn; minimize/reopen; reach the end. Assert no lost content, stable semantic location, directional progress, and 100% completion. This catches UI regressions before they reach you.

2. Pagination and input polish
Make fullscreen spreads feel intentional: keyboard arrows, edge clicks, touch/swipes, disabled states at boundaries, predictable animation, and mobile remaining a calm vertical reader. The test suite should cover each input method.

3. Typography and layout polish
Refine column width, line length, leading, margins, large-text behavior, and tablet/mobile breakpoints. This is where the reader becomes pleasurable rather than merely functional.

4. Loading and transitions
Ensure opening, restoring, appending, and prepending content never look broken: a brief purposeful loader when needed, no blank state, and no perceptible jump when a chunk is added.

Then stabilize and improve content

5. Source markup audit
Validate every partition for valid block structure, stable/ordered IDs, monotonic word offsets, clean encoding, and sensible section boundaries. This protects the reader from malformed source material and is prerequisite work for expansion.

6. Quote curation
Once source passages are stable, replace automatic first-paragraph selections with short, complete, memorable quotations. Validate that every quote has a precise semantic location, reads well alone, is not duplicated, and links to the correct passage.

Then add calm discovery features

7. Progress magnifier and location context
Keep the default line minimal. Later, hover/focus/touch can expand it into a nearby chapter/section/verse label; a subsequent slice can permit clicking to jump. The semantic timeline already supports this efficiently.

8. Bookmarks and settings
Decide whether a bookmark is a reading marker, favorite passage, or annotation before adding controls. Settings should remain curated: typography, theme, text size, and library scope—not an overwhelming control panel.

9. Curated library expansion
Add new public-domain works through a provenance-aware ingestion path: source, rights status, parser profile, source audit, semantic timeline, quote curation, and acceptance review. “Browse and load online works” should initially be a carefully bounded catalog, not arbitrary URLs.
